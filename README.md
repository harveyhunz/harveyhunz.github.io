# CueScore Studio - Official Website

This repository contains the source code for the official landing page and developer assets for **CueScore Studio**, a professional Snooker scoring and video overlay application for iOS.

## 🚀 Live Site
Check out the live page here: [https://harveyhunz.github.io/cuescorestudio-web/](https://harveyhunz.github.io/cuescorestudio-web/)

## 🛠 Features
- **App Store Assets:** Host for `app-ads.txt` and Privacy Policy.
- **Support:** Technical support information for app users.
- **Responsive Design:** A clean, Apple-inspired interface for Snooker players.
